## Book Sales Exploratory Data Analysis 

This project explores a cleaned book sales dataset to uncover trends in publishing, pricing, and reader engagement. The analysis focuses on understanding how factors such as ratings, publication year, and book attributes influence overall popularity.

Using Python (Pandas, Matplotlib, Seaborn), the dataset was analyzed to generate meaningful visual insights that highlight key patterns in book performance and market trends.

### Tool
- Python
### Library
- Pandas
- Matplotlib
- Seaborn
